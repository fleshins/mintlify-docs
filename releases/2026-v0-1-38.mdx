This release delivers **more consistent filtering across pages**, **faster access to customer signals**, **clearer and more actionable insights**, **improved dashboard and profile performance**, and **stronger admin controls**.

Below are the most important changes in this release (not every internal tweak, just the ones we think deliver the most value).

---

## 🔎 **Faster, more consistent filtering**

- **Universal filter bar across key pages:** The same filter bar is now available on Dashboard, Explorer, Account, and User pages, with support for using the same saved filters and criteria across those views. — Teams can move between pages without rebuilding their analysis each time.
- **Quick shortcuts for wins and issues:** New All Wins and All Issues shortcuts make it easier to focus on positive or negative customer signals. — Users can get to the right conversations and trends faster.
- **Clearer scoped profile results:** Profile pages now show locked context filters when results are limited to a specific account or user. — It is easier to understand exactly what data is being shown.
- **Improved Explorer starting view:** Explorer now opens to Conversations by default and shows clearer start times and turn counts. — Users can review conversation activity more quickly with less setup.

## 💡 **More actionable insights**

- **Recommendations appear first:** Insight details now show recommendations before supporting evidence. — Users can find the next step faster without scanning through the full explanation first.
- **Higher-quality insight generation:** Insight generation has been improved to produce more focused results with clearer supporting evidence. — Teams can act on insights with more confidence.
- **Export options are clearer:** The export action now reflects support for both Jira and Linear. — Users can more easily send insights into the tools where work gets tracked.

## 📊 **Clearer dashboards and profile views**

- **Complete yearly chart data:** Dashboard yearly charts now display complete data across metrics. — Users get a more accurate view of performance over time.
- **Faster page loading with placeholders:** Dashboard and profile pages now load faster and show loading placeholders while content is prepared. — Pages feel more responsive and users get better feedback while waiting.
- **Improved chart labels and links:** Chart labels and View in Explorer links are clearer and remain aligned with the selected time range. — Users can interpret charts more easily and drill into the right data.

## ⚙️ **More control for admins**

- **Branding and logo management:** Admins can now manage organization branding and customer account logos directly. — Teams can keep their workspace and customer records better organized and on-brand.
- **Manual name edits are preserved:** Admins can correct account and user names without those changes being overwritten by future imports. — Data stays cleaner and requires less repeated manual cleanup.
- **Faster organization switching:** Staff users can switch between organizations more quickly from the admin area, including with keyboard navigation. — Multi-org workflows take fewer clicks and feel faster.

## 🛠️ **Smoother setup, imports, and reliability**

- **Clearer import and setup guidance:** Magic Importer copy is clearer, import error links now open the exact row with an issue, and successful SDK setup now shows a clearer confirmation modal. — Teams can complete setup and fix import problems with less guesswork.
- **External source links in conversations:** Conversations can now show an external source link directly in the header when one is available. — Users can jump to the original source more easily for added context.
- **Improved handling for heavy workloads:** Large message bodies, reindexing jobs, and insight generation retries are now handled more reliably, and saved filter names can be reused safely across organizations. — The product works more consistently at scale and is easier to manage across teams.

Thanks for using Brixo! We hope these updates make your day-to-day workflows smoother, faster, and more intuitive.
